### What Claude built

**Routes** are thin: validate, call the service, translate "not found" into a 404, return.

```python title="backend/app/api/v1/tasks.py (trimmed)"
router = APIRouter(prefix="/api/tasks", tags=["tasks"])
DbDep = Annotated[AsyncSession, Depends(get_db)]


@router.get("", response_model=list[TaskResponse], response_model_by_alias=True)
async def list_tasks(db: DbDep) -> list[Task]:
    return await task_service.get_all_tasks(db)


@router.post("", response_model=TaskResponse, response_model_by_alias=True,
             status_code=status.HTTP_201_CREATED)
async def create_task(data: TaskCreate, db: DbDep) -> Task:
    return await task_service.create_task(db, data)


@router.put("/{task_id}", response_model=TaskResponse, response_model_by_alias=True)
async def update_task(task_id: int, data: TaskUpdate, db: DbDep) -> Task:
    task = await task_service.update_task(db, task_id, data)
    if task is None:
        raise HTTPException(status_code=404, detail=f"Task {task_id} not found")
    return task


@router.delete("/{task_id}", status_code=status.HTTP_204_NO_CONTENT)
async def delete_task(task_id: int, db: DbDep) -> None:
    if not await task_service.delete_task(db, task_id):
        raise HTTPException(status_code=404, detail=f"Task {task_id} not found")
```

`response_model_by_alias=True` is the important detail: it makes FastAPI send `assignedRole` and `createdAt`, as the frontend expects.

**The service** holds the logic and knows nothing about HTTP:

```python title="backend/app/services/task_service.py (trimmed)"
async def update_task(db: AsyncSession, task_id: int, data: TaskUpdate) -> Task | None:
    task = await db.get(Task, task_id)
    if task is None:
        return None

    # Only change the fields the client actually sent
    patch = data.model_dump(exclude_unset=True)
    for field, value in patch.items():
        setattr(task, field, value)

    await db.commit()
    await db.refresh(task)
    return task
```

`model_dump(exclude_unset=True)` means a request that only sends `{"state": "editing"}` changes only the state, instead of wiping the title and description.

**`main.py`** registers the router and enables CORS for the origins the frontend may run on, plus a `/health` endpoint.

### What "idempotent" means

An **idempotent** operation gives the same result no matter how many times you run it. Seed scripts often run on every deploy or restart. Without this rule, every restart would insert the same five tasks again.

Claude's script checks each `id` before inserting:

```python title="backend/seed.py (trimmed)"
async def seed() -> None:
    records = json.loads(SEED_FILE.read_text(encoding="utf-8"))
    async with AsyncSessionLocal() as db:
        for rec in records:
            if await db.get(Task, rec["id"]) is not None:
                print(f"  SKIP   id={rec['id']}")
                continue
            db.add(Task(
                id=rec["id"],
                title=rec["title"],
                description=rec["description"],
                assigned_role=AssignedRole(rec["assigned_role"]),
                state=TaskState(rec["state"]),
                created_at=date.fromisoformat(rec["created_at"]),
            ))
        await db.commit()
```

Run it:

```bash
cd backend
uv run python seed.py
```

Claude reported that two of the ids already existed from its earlier `curl` tests, skipped them, and inserted the rest. Back in Swagger, `GET /api/tasks` now returns all **five** tasks.
