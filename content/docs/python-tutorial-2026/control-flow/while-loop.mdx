So far every line of a program has run once, or not at all. Many tasks need a line to run again and again. Go through every value of a list. Read a file one character at a time. Download something piece by piece. Or print the same text ten times.

You could copy the line ten times. For a billion times that plan fails. The better plan is to write the line once and tell Python to repeat it. A statement that repeats a block of code is called a **loop**.

Python has two loops, `while` and `for`. This lesson covers `while`. The next one, [Nested while Loop](/docs/python-tutorial-2026/control-flow/nested-while-loop), puts one `while` inside another. After that comes [The for Loop](/docs/python-tutorial-2026/control-flow/for-loop).

## Step 1: A loop that never stops

Create a new file, `while_demo.py`. One `print` prints one line. To repeat it, the lesson puts it under `while True:`.

{/* check: skip */}
```python title="while_demo.py"
while True:
    print("Hello World")
```

`while` is a keyword. It is followed by a condition and a colon, and below it comes an indented block, the same shape as an `if`. The difference is what happens after the block:

- An `if` checks its condition once and runs the block once.
- A `while` checks its condition, runs the block, and then goes back and checks again. It repeats for as long as the condition is true.

The block can hold many lines. Here it holds one.

Run the file with `python while_demo.py`. The condition is `True`, which is always true, so the loop never ends. `Hello World` fills the terminal faster than you can read. A loop like this is called an **infinite loop**.

<Callout type="warn" title="Stop a running program with Ctrl+C">
Click into the terminal, hold the Ctrl key and press C. Python stops the program at once and shows what it was doing at that moment.
</Callout>

```text
Hello World
Hello World
Traceback (most recent call last):
  File "C:\...\FirstProject\while_demo.py", line 2, in <module>
    print("Hello World")
    ~~~~~^^^^^^^^^^^^^^^
KeyboardInterrupt
```

This is not a bug in your code. `KeyboardInterrupt` is Python's way of saying "stopped from the keyboard". The path is cut short here with `...`. On your computer that line shows the full path of your own file, so it will look different. The line number can differ too. It is the line Python was working on at the moment you pressed the keys. The video shows line 3, because the file there begins with an empty line.

While the loop runs, the instructor opens the Windows Task Manager. The processor is busy at around 30 percent, only to print the same two words. An application that gets stuck in such a loop by mistake keeps the processor busy in the same way, and that can slow down the whole computer.

So `True` is not a useful condition here. The opposite is no better. With `while False:` the condition is false at the very first check, and the block never runs:

```python title="while_demo.py"
while False:
    print("Hello World")
```

This program prints nothing. The lesson needs something in between: true for a while, then false.

## Step 2: Count with a counter

To print the line five times, the program has to count: one, two, three, four, five. Counting needs a variable, called a **counter**. Any name works. By tradition programmers use `i`, and then `j` and `k` when they need more.

Start at 1 and repeat while the counter is at most 5:

{/* check: skip */}
```python title="while_demo.py"
i = 1

while i <= 5:
    print("Hello World")
```

Run this and it is endless again. Stop it with Ctrl+C. The reason: `i` is 1, and nothing ever changes it. 1 is less than 5 every time the condition is checked.

The loop has to change the counter itself, inside its block:

```python title="while_demo.py"
i = 1

while i <= 5:
    print("Hello World")
    i += 1
```

```text
Hello World
Hello World
Hello World
Hello World
Hello World
```

`i += 1` adds 1 to `i`. It is short for `i = i + 1`.

A counting loop has three parts, and all three are needed:

| Part | In the code | Job |
| --- | --- | --- |
| Start value | `i = 1` | Set once, before the loop |
| Condition | `i <= 5` | Checked before every round |
| Change | `i += 1` | Inside the block, so the condition becomes false at some point |

## Step 3: What is i after the loop?

Add one line after the loop, without indentation, so it is outside the block:

```python title="while_demo.py"
i = 1

while i <= 5:
    print("Hello World")
    i += 1

print(i)
```

Guess the number before you read on. Many people say 5, because the loop counts to 5.

```text
Hello World
Hello World
Hello World
Hello World
Hello World
6
```

It is 6. The lesson shows why with the debugger from [else and Debugging](/docs/python-tutorial-2026/control-flow/else-and-debugging): a breakpoint on the `while` line, then Step Over, with an eye on the value of `i`.

| `i` when the condition is checked | `i <= 5` | What happens |
| --- | --- | --- |
| 1 | True | Prints `Hello World`, `i` becomes 2 |
| 2 | True | Prints `Hello World`, `i` becomes 3 |
| 3 | True | Prints `Hello World`, `i` becomes 4 |
| 4 | True | Prints `Hello World`, `i` becomes 5 |
| 5 | True | Prints `Hello World`, `i` becomes 6 |
| 6 | False | The loop ends. `print(i)` prints `6` |

The block runs five times. The condition is checked six times. The loop can only end when the condition is false, and `i <= 5` is false for the first time when `i` is 6.

## Additions beyond the lesson

**Python has no do-while loop.** The lesson lists `while`, `do-while` and `for` as the common loops of programming languages. Python has `while` and `for` only.

**Many programmers count from 0.** Starting at 0 with the condition `i < 5` also gives five rounds:

```python title="count_from_zero.py"
i = 0

while i < 5:
    print(i)
    i += 1
```

```text
0
1
2
3
4
```

## Mistakes and fixes

| What you see | Cause | Fix |
| --- | --- | --- |
| `Hello World` without end | The condition is `True`, or the counter never changes. Both happen in the lesson | Press Ctrl+C. Then add `i += 1` inside the block |
| A traceback that ends with `KeyboardInterrupt` | You stopped the program with Ctrl+C | Nothing to fix. This is the normal way to stop a running program |
| The loop is endless although `i += 1` is in the file | `i += 1` is not indented, so it stands after the loop and is never reached | Indent it so that it is part of the block |
| Nothing is printed | The condition is false at the first check, as with `while False:` | Check the start value and the condition |
| `print(i)` shows 6 and not 5 | The loop ends when `i <= 5` is false, and that first happens at 6 | Nothing to fix. Expect the counter to be one step past the limit |
| `SyntaxError: expected ':'` | The colon after the condition is missing | End the `while` line with `:` |
| `IndentationError: expected an indented block after 'while' statement on line 3` | The block is not indented. The number is the line of your `while` | Indent the block with 4 spaces |
| `SyntaxError: invalid syntax` at `i++` | Python has no `++` operator | Write `i += 1` |
