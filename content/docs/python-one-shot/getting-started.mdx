This section is the written companion to one video: the **Python Tutorial for Beginners 2026** by Navin Reddy on the Telusko channel. The video is about eight and a half hours long and has 54 chapters. These docs follow it in the same order, with the code, the output and the mistakes that happen on the way.

You can use the pages in three ways:

- **With the video.** Every lesson page starts with the video at the right moment. Watch a chapter, then read the page to fix it in your mind and to copy the code.
- **Without the video.** Each page is complete by itself. Every prompt session and every program is written out, with its output.
- **As a reference later.** Every page ends with a table of mistakes and their fixes, and with exercises.

No programming knowledge is expected. The first page starts from the question of what Python is.

## What you need

| Requirement | Details |
| --- | --- |
| A computer | Windows is used in the video. Python works the same way on macOS and Linux, and the setup page has notes for both |
| Python 3 | The video installs Python 3.13. Any current Python 3 version works. One lesson, the `match` statement, needs 3.10 or newer |
| An editor | The video uses the Python prompt and IDLE at first, then mostly VS Code. PyCharm and Jupyter Notebook are shown too. All are free to start with |

## How the code is shown

The early lessons type directly into the Python prompt. Those sessions look like this, with the three arrows in front of what you type and the answer on the next line:

```python
>>> 2 + 3
5
```

The first small files appear in the setup lessons. From the functions lessons on, almost all code lives in files that are run from the terminal. Those are shown with the file name on top, and the output in a block of its own below:

```python title="Demo.py"
print("Hello")
```

```text
Hello
```

Type the code yourself where you can. Copying and pasting teaches much less.

## How these docs were checked

A mistake in a lesson costs a learner time, so the code on these pages was not only copied from the screen.

- **Run.** Every prompt session and every program on these pages was run with Python 3.13, and the output on the page was compared with the real output by a script. The few blocks that cannot be compared automatically, such as error messages with a file path, memory addresses or output whose order changes from run to run, were run by hand.
- **Compared with the video.** The code and the outputs were taken from the video frame by frame. Where the video does not show an output, the page shows the real output and says so.
- **Corrected where needed.** In a long live recording, a word or a claim is sometimes not exact. Where that happens, the page keeps the correct statement and adds a short note about what the video says. Such notes were checked against the official Python documentation or by running code.

Each page has a box named "Checked for these docs" that says what was run for that page and what could not be checked.

Error messages are quoted as Python 3.13 prints them. Newer Python versions word a few of them a little differently, and often add a helpful hint. The meaning stays the same.
