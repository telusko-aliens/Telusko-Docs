You have used operators since the first time you typed `2 + 3`. An **operator** is a symbol or a word that does something with values. The values it works on are called **operands**.

This lesson collects the operators into groups. Arithmetic operators calculate. Assignment operators store. Relational operators compare two values and answer with `True` or `False`. Logical operators join several such answers into one.

The last two groups are the ones to watch. A program that can compare and combine conditions can make decisions, and that is where the course is heading next.

## Step 1: Arithmetic operators

```python
>>> a = 3
>>> b = 2
>>> a + b
5
>>> a - b
1
>>> a * b
6
>>> a / b
1.5
>>> a // b
1
>>> a % b
1
```

These are the operators from [IDLE and Number Operations](/docs/python-one-shot/python-basics/idle-and-number-operations), now used with variables. `/` gives the exact result as a float, `//` gives the quotient, and `%`, called mod, gives the remainder.

## Step 2: Assignment and its shortcuts

To raise `a` by 2, calculate `a + 2` and store the result in `a` again:

```python
>>> a = 3
>>> a = a + 2
>>> a
5
```

The line uses two operators. `+` adds, and `=` assigns. The `=` is the **assignment operator**. It was already at work in `a = 3`. Python first works out the right side, 3 plus 2, and then puts the result into the name on the left.

Because the pattern "change a variable by some amount" is so common, there is a shorter way to write it:

```python
>>> a = 5
>>> a += 2
>>> a
7
```

`a += 2` means the same as `a = a + 2`. The instructor calls it a shortcut or shorthand.

Many languages have an even shorter form for adding 1, written `a++`. Python does not:

```python

```

To add 1, use the same shorthand as before:

```python
>>> a = 7
>>> a += 1
>>> a
8
```

The shorthand exists for the other arithmetic operators too. This table is an addition to the lesson. Each row starts again from `a = 7`:

| Shorthand | Same as | `a` afterwards |
| --- | --- | --- |
| `a += 2` | `a = a + 2` | `9` |
| `a -= 2` | `a = a - 2` | `5` |
| `a *= 2` | `a = a * 2` | `14` |
| `a /= 2` | `a = a / 2` | `3.5` |
| `a //= 2` | `a = a // 2` | `3` |
| `a %= 2` | `a = a % 2` | `1` |

## Step 3: Assign two variables in one line

Giving values to `x` and `y` normally takes two lines. Python can do it in one:

```python
>>> x,y = 6,5
>>> x
6
>>> y
5
```

The first value goes to the first name and the second value to the second name. The number of names on the left must match the number of values on the right.

## Binary and unary operators

In `a + b` and `a - b` the operator stands between two operands. Such an operator is called a **binary operator**. Binary here means "with two operands".

An operator can also work on a single operand. Then it is a **unary operator**. The minus sign in front of a value is the usual example:

```python
>>> a = 8
>>> -a
-8
>>> a
8
>>> a = -a
>>> a
-8
```

`-a` gives the negated value and leaves `a` as it is. The third line proves it: `a` is still 8. To change the variable itself, assign the result back to it with `a = -a`.

## Step 4: Relational operators

**Relational operators** compare two values. The answer is always a boolean, the type with the two values `True` and `False` from [Data Types](/docs/python-one-shot/data-structures-and-types/data-types).

```python
>>> a = 4
>>> b = 3
>>> a > b
True
>>> a < b
False
>>> a <= b
False
```

Maths has one symbol for "less than or equal to". The keyboard does not, so Python writes it with two characters, `<=`. With 4 and 3 the answer is `False`: 4 is not less than 3, and it is not equal to 3.

Now make both values the same:

```python
>>> a = 4
>>> b = 4
>>> a <= b
True
>>> a >= b
True
>>> a == b
True
>>> a != b
False
```

`a <= b` is `True` now. 4 is not less than 4, and it is equal to 4, and one of the two is enough.

To test whether two values are equal, write a double equals sign. A single `=` is already taken. It assigns. `!=` asks the opposite question, and the exclamation mark in it stands for "not".

| Operator | Question | With `a = 4`, `b = 4` |
| --- | --- | --- |
| `a > b` | Is `a` greater than `b`? | `False` |
| `a < b` | Is `a` less than `b`? | `False` |
| `a >= b` | Is `a` greater than or equal to `b`? | `True` |
| `a <= b` | Is `a` less than or equal to `b`? | `True` |
| `a == b` | Are they equal? | `True` |
| `a != b` | Are they different? | `False` |

The first two answers in the table were worked out for these docs. The lesson runs `>` and `<` with `b = 3`.

## Step 5: Logical operators

Real decisions rarely depend on one condition. The instructor's example is an umbrella. Do you take one when you leave the house? In the rainy season, yes, if you are going to the office. On a Sunday without office, no, rain or not. And nobody takes an umbrella to play cricket. You take it only when two things are true together: it is the rainy season and it is a working day.

In the prompt, the lesson sets `b = 5` and checks two conditions one at a time:

```python
>>> a = 4
>>> b = 5
>>> a < 10
True
>>> b > 1
True
```

Writing both on one line does not combine them:

{/* check: skip */}
```python
>>> a < 10 b > 1
  File "<python-input-256>", line 1
    a < 10 b > 1
           ^
SyntaxError: invalid syntax
```

Something has to stand between the two conditions. That something is a **logical operator**, and Python uses plain English words for them: `and`, `or` and `not`.

```python
>>> a = 4
>>> b = 5
>>> a < 10 and b > 1
True
>>> a < 10 or b > 1
True
```

Both lines give `True`, so `and` and `or` look the same here. They are not. Both conditions happen to be true, and that is the one case in which the two agree. Change the second condition so that it is false:

```python
>>> a = 4
>>> b = 5
>>> a < 10 or b > 10
True
>>> a < 10 and b > 10
False
```

`a < 10` is `True` and `b > 10` is `False`. `or` is satisfied with one true condition. `and` insists on both.

![Logical_Operators](https://dyz1pdcuffwr5.cloudfront.net/PythonOneShot/py1s-logical-operators.svg)

### Truth tables

A **truth table** lists the result for every possible combination of inputs. With two conditions, c1 and c2, there are four combinations. The video writes the tables with 1 for `True` and 0 for `False`, which matches what `int(True)` and `int(False)` gave in the last lesson.

| c1 | c2 | c1 `and` c2 | c1 `or` c2 |
| --- | --- | --- | --- |
| `True` | `True` | `True` | `True` |
| `True` | `False` | `False` | `True` |
| `False` | `True` | `False` | `True` |
| `False` | `False` | `False` | `False` |

Two sentences sum it up:

- `and` gives `True` in one case only: both conditions are true.
- `or` gives `False` in one case only: both conditions are false.

The lesson confirms the last row for `or`:

```python
>>> a = 4
>>> b = 5
>>> a > 10 or b > 10
False
```

### not

The third logical operator works on a single value and reverses it:

```python
>>> result = True
>>> result
True
>>> not result
False
```

| Value | `not` value |
| --- | --- |
| `True` | `False` |
| `False` | `True` |

The exclamation mark does not work here. It exists only inside `!=`. To reverse a boolean, write the word `not`.

## Additions beyond the lesson

**Which logical operator goes first.** In a line with several logical operators, Python applies `not` first, then `and`, then `or`. Comparisons are done before all three. Brackets change the order and make it visible:

```python
>>> a = 4
>>> b = 5
>>> not a < 10 and b > 10
False
>>> not (a < 10 and b > 10)
True
```

In the first line, `not` belongs to `a < 10` only. That gives `False and False`, which is `False`. In the second line the brackets are worked out first. They give `False`, and `not` turns that into `True`.

**Bitwise operators.** In [IDLE and Number Operations](/docs/python-one-shot/python-basics/idle-and-number-operations), `8 ^ 10` gave 2 instead of a power. This lesson does not cover the reason, so here it is in short. A computer stores a whole number in binary, as a row of **bits** that are each 0 or 1. Bitwise operators compare two numbers bit by bit. `&` and `|` use the truth tables above on every pair of bits, with 1 as true and 0 as false. `bin` shows the bits of a number after the prefix `0b`:

```python
>>> bin(12)
'0b1100'
>>> bin(10)
'0b1010'
>>> 12 & 10
8
>>> 12 | 10
14
>>> 12 ^ 10
6
>>> 8 ^ 10
2
```

Written under each other, the bits explain the results:

```text
12            1 1 0 0
10            1 0 1 0

12 & 10       1 0 0 0    which is 8     and: 1 where both bits are 1
12 | 10       1 1 1 0    which is 14    or:  1 where at least one bit is 1
12 ^ 10       0 1 1 0    which is 6     xor: 1 where the two bits differ
```

The operator `^` is called exclusive or, or xor for short. For `8 ^ 10`, the bits are 1000 and 1010. They differ in one place only, which leaves 0010, and that is 2. Use `and` and `or` for conditions. The bitwise operators are for work on the bits of integers. The same symbols `|`, `&` and `^` have a second meaning for sets, as shown in [Sets](/docs/python-one-shot/data-structures-and-types/sets).

## Mistakes and fixes

| What you see | Cause | Fix |
| --- | --- | --- |
| `SyntaxError: invalid syntax` after `a++` | Python has no `++` operator. This is shown in the lesson | Write `a += 1` |
| `SyntaxError: invalid syntax` after `a < 10 b > 1` | Two conditions stand next to each other with nothing between them. This happens in the lesson | Join them with `and` or `or` |
| Typing `a = b` shows nothing, and `a` has changed | A single `=` assigns. It does not compare | Use `a == b` to compare |
| `SyntaxError: invalid syntax` after `a => b` or `a =< b` | The equals sign comes second in these operators | Write `a >= b` or `a <= b` |
| `a =+ 2` makes `a` equal to 2 | The two characters are in the wrong order, so Python reads `a = +2` | Write `a += 2` |
| `SyntaxError: invalid syntax` after `!result` | The exclamation mark only exists inside `!=` | Write `not result` |
| `TypeError: cannot unpack non-iterable int object` after `x,y = 6` | Two names on the left and one value on the right | Give one value for each name: `x,y = 6,5` |
| `-a` shows the negative value, and `a` is unchanged | A unary minus does not store anything | Write `a = -a` |
