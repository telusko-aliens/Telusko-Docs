Go, also called Golang, is an open-source programming language created at Google. It is compiled, statically typed, and designed to be simple, fast, and easy to read. That mix is why it powers a large amount of modern backend and cloud software, including tools like Docker and Kubernetes.

## Why Learn Go

- **Simple to learn** - a small language with little syntax to memorize
- **Fast** - compiles to a single native binary that starts instantly
- **Built for the backend** - servers, APIs, tools, and networked services
- **Great tooling** - formatting, testing, and building all come in the box

## What This Course Covers

This series follows a beginner Golang tutorial lecture by lecture, from setup and your first program through variables, control flow, collections, pointers, functions, structs, methods, packages, and scope - finishing with a hands-on Todo App project.
