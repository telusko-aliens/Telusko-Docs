Before a single line of Go can run, the language has to live on your machine. The good news is that this is one of the friendliest setups in programming: one download, one confirmation, and a two-click editor extension. Once it is done, everything that follows is just writing code.

## Get Go From the Source

Go is distributed from its official site, and there is only one place you need.

<Steps>

<Step>
### Open go.dev

Head to [go.dev](https://go.dev) and find the downloads page. It shows the latest release for each operating system.
</Step>

<Step>
### Take the stable version

Always choose the **stable** release, not a beta or release candidate. Stable builds are tested and steady; pre-release ones can carry bugs you do not want to debug on day one.
</Step>

<Step>
### Run the installer for your OS

Grab the installer for **macOS**, **Windows**, or **Linux**, then run it and follow the prompts. That is the whole installation.
</Step>

</Steps>

<Callout type="info">
One worry you can set aside: Go is **backward compatible**. Code you write today keeps working when you update to a newer version later, so installing the newest stable release is always safe.
</Callout>

## Did It Work?

Open your terminal and type a single word:

```bash
go
```

If Go is installed, it prints a list of the commands it understands. To see the exact version, ask:

```bash
go version
```

```text
go version go1.22.0 windows/amd64
```

A version number means you are ready. If instead the terminal says the command is not found, the fix is almost always the same: close that terminal and open a fresh one, so it picks up the newly installed Go.

## Picking an Editor

You can write Go in any text editor, but the right one makes learning smoother. Two names come up:

| Editor | Notes |
| ------ | ----- |
| **GoLand** | A dedicated Go IDE from JetBrains. Powerful and common in professional shops, but it is a paid product. |
| **VS Code** | Free, light, and excellent for learning. This is what we use. |

## Turning VS Code Into a Go Editor

Plain VS Code does not know Go until you add one thing.

<Steps>

<Step>
### Install VS Code

Download [VS Code](https://code.visualstudio.com) if you do not already have it.
</Step>

<Step>
### Add the official Go extension

Open the Extensions panel, search for **"Go"**, and install the official extension.
</Step>

</Steps>

That extension is what earns VS Code its place here. It gives you **code completion**, so suggestions appear as you type, and **real-time error detection**, so Go-specific mistakes are underlined the moment you make them instead of surfacing only when you try to run. The first time you open a `.go` file, VS Code will offer to install a small set of Go tools - say yes, and it configures the rest for you.

With Go on your machine and an editor that understands it, the next step is the one every programmer remembers: your first program.
