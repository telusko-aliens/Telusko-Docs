Picture a small program that works out the area and perimeter of a rectangle, and you have written the numbers `3` and `4` straight into every formula. It runs fine. Then the rectangle changes size. Now you are hunting through the code, changing `3` and `4` in the area line, the perimeter line, the printed output. Miss one and the program is quietly, confidently wrong.

That pain is the reason variables exist.

## Name It Once

Here is the fragile version, with the numbers baked in:

```go
fmt.Println("Area:", 3*4)
fmt.Println("Perimeter:", 2*(3+4))
```

Change the dimensions and you are editing by hand in several places, praying you keep them in sync. A variable ends that. It lets you write a value down **once**, give it a name, and use that name everywhere. Change the one definition, and everything downstream follows.

## The var Keyword

Go declares a variable with `var`. You give it a name and a value, and Go quietly works out the type:

```go
var length int = 7
var width int = 5
```

`length` and `width` are now names you can use anywhere in the program. And Go **infers the type** from the value you assign: it sees `7` and knows it is an `int`; hand it `10.8` and it settles on `float64`.

<Callout type="info">
That automatic type-figuring is called type inference. There are even shorter ways to declare variables, which the next lesson covers, but `var` is the clear, explicit place to start.
</Callout>

## The Rectangle, Rebuilt

```go
package main

import "fmt"

func main() {
    var length int = 7
    var width int = 5

    area := length * width
    perimeter := 2 * (length + width)

    fmt.Println("Length:", length)
    fmt.Println("Width:", width)
    fmt.Println("Area:", area)
    fmt.Println("Perimeter:", perimeter)
}
```

```text
Length: 7
Width: 5
Area: 35
Perimeter: 24
```

Now the whole thing bends to a single edit. Change `length` or `width` at the top and the area, the perimeter, and every printed line update on their own. Nothing else gets touched.

```text
   hard-coded 3 and 4   →  edit every line, keep them in sync
   length = 7, width = 5 →  edit one place, everything follows
```

One detail you may have spotted: the code mixes `var length int = 7` with `area := length * width`. Both create variables. That `:=` is a shorter way to declare and assign at once, and pulling those styles apart is exactly what the next lesson is for.
