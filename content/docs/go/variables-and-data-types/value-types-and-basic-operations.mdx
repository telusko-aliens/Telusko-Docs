---
title: Value Types and Basic Operations
description: Go's four everyday value types and the operations that come naturally to each.
---

Strip a program down to its atoms and you are left with values: words, numbers, and yes-or-no answers. Go gives you four core types to hold them, and each type comes with the operations that make sense for it. Learn these four and the operations they invite, and you have the vocabulary for everything else.

## The Four You Will Reach For

| Type | Holds | Example |
| ---- | ----- | ------- |
| `string` | text | `"Go"` |
| `int` | whole numbers, negatives included | `123` |
| `float` | numbers with a decimal point | `10.8` |
| `bool` | a single truth value | `true` |

Words, counts, measurements, and yes/no. Between them, these four cover the overwhelming majority of the values you will ever store.

## What Each Type Lets You Do

Numbers want arithmetic. Add them, subtract them, and so on:

```go
fmt.Println(123 - 23)     // 100
fmt.Println(10.8 + 11.23) // 22.03
```

Booleans want logic. Two operators do most of the work: `&&` (AND) is `true` only when both sides are true, and `||` (OR) is `true` when at least one side is:

```go
fmt.Println(false && true) // false, both would need to be true
fmt.Println(false || true) // true, one is enough
```

Strings want joining. The `+` operator glues two of them together, which is called concatenation:

```go
fmt.Println("Go" + " Tutorial") // Go Tutorial
```

Look closely at that space inside `" Tutorial"`. Go joins strings exactly as written and adds nothing, so any spacing between words is yours to include.

## Seeing Them Together

```go
package main

import "fmt"

func main() {
    // String
    fmt.Println("Go" + " Tutorial") // Concatenation

    // Integer
    fmt.Println(123 - 23) // 100

    // Float
    fmt.Println(10.8 + 11.23) // 22.03

    // Boolean
    fmt.Println(false && true) // false
    fmt.Println(false || true) // true
}
```

## A Layout Rule That Bites Early

Two habits from other languages will trip you up in Go. First, a runnable file always needs `package main` and a `main()` function. Second, and more surprising, the opening brace `{` has to sit on the **same line** as the declaration.

<Callout type="warn">
This is not a style preference. Go automatically inserts line endings as it reads your code, so putting `{` on its own line actually breaks the program. Keep it right after `func main()`.
</Callout>

One thing you will *not* have to fuss with is imports. The Go extension in VS Code adds the `import "fmt"` line for you the moment you use `fmt`, so those appear as if by magic while you focus on the logic.
