## The Building Blocks

Before you can do anything interesting in Go, you need values to work with. Go has a small set of core **value types** for text, numbers, and true/false logic, and a handful of operators to combine them. This lesson introduces those types and shows the basic operations each one supports.

## Core Value Types

Go supports several fundamental types you will use constantly:

| Type | Used for | Example |
| ---- | -------- | ------- |
| `string` | text | `"Go"` |
| `int` | whole numbers, including negatives | `123` |
| `float` | numbers with decimal points | `10.8` |
| `bool` | logical values, `true` or `false` | `true` |

These four cover the vast majority of everyday values: words, counts, measurements, and yes/no answers.

## Basic Operations

Each type supports operations that make sense for it.

### Arithmetic on numbers

Addition and subtraction (and other arithmetic) work on `int` and `float` values:

```go
fmt.Println(123 - 23)     // 100
fmt.Println(10.8 + 11.23) // 22.03
```

### Logical operators on booleans

Booleans are combined with logical operators. The two most common:

- `&&` (AND) returns `true` only when **both** sides are true
- `||` (OR) returns `true` when **at least one** side is true

```go
fmt.Println(false && true) // false - both must be true
fmt.Println(false || true) // true  - one is enough
```

### String concatenation

The `+` operator joins two strings together, which is called concatenation:

```go
fmt.Println("Go" + " Tutorial") // Go Tutorial
```

Note the space inside `" Tutorial"` - Go joins the strings exactly as given, so you add spacing yourself.

## Essential Coding Practices

A few Go rules show up the moment you write real code:

- **Package and function:** to create an executable Go file, you need `package main` and a `main()` function, as you saw in the first program.
- **Formatting:** Go is strict about layout. The opening curly brace `{` must sit on the **same line** as the function declaration, not on its own line. This is required, not just a style choice.
- **Auto-import:** the Go extension in VS Code manages imports for you. When you use `fmt`, it adds the `import "fmt"` line automatically, so you rarely type imports by hand.

<Callout type="info">
The brace rule is not just convention - Go's compiler inserts line endings automatically, so putting `{` on its own line actually breaks the program. Keep the opening brace on the same line as `func main()`.
</Callout>

## Sample Code

Putting the value types and operations together:

```go
package main

import "fmt"

func main() {
    // String
    fmt.Println("Go" + " Tutorial") // Concatenation

    // Integer
    fmt.Println(123 - 23) // 100

    // Float
    fmt.Println(10.8 + 11.23) // 22.03

    // Boolean
    fmt.Println(false && true) // false
    fmt.Println(false || true) // true
}
```

## Common Mistakes

A frequent early slip is putting the opening `{` on its own line out of habit from another language. In Go this breaks the program, so keep it on the same line as the declaration.

Another is forgetting to add spaces when concatenating strings. `"Go" + "Tutorial"` produces `GoTutorial`; you include any spacing you want inside the strings themselves.

## Summary

Go's core value types are `string` for text, `int` for whole numbers, `float` for decimals, and `bool` for `true`/`false`. You operate on them with arithmetic (`+`, `-`, and more) on numbers, the logical operators `&&` and `||` on booleans, and `+` to concatenate strings. Alongside these, remember the practical rules: an executable needs `package main` and `main()`, the opening brace stays on the same line, and the VS Code Go extension handles imports like `fmt` for you.
