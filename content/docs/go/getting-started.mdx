Welcome to the Go course. This series takes you from installing Go to building a complete Todo App, following the lectures in order so each topic builds on the one before it.

The course is organized into the following sections, mapping one page to each lecture:

## 01 - Getting Started

Setting up Go and writing your first program.

## 02 - Variables and Data Types

Value types and basic operations, declaring variables, data types, and converting between them.

## 03 - User Inputs

Reading input from the user, in two parts.

## 04 - Control Flow

Making decisions with if-else and switch, and repeating work with loops.

## 05 - Collections

Storing groups of values with arrays, slices, and maps.

## 06 - Core Concepts

Pointers, functions, structs, and methods - the building blocks of real Go programs.

## 07 - Packages and Scope

Organizing code into packages and understanding how scope works.

## 08 - Final Project

Building a Todo App in Go, step by step.
