This section is the written companion to one video: the **LangChain4j Full Course in One Shot** by Haider Abbas on the Telusko channel. The video is five hours long and has 37 chapters. These docs follow it in the same order, one page for each topic, with the code, the output and the mistakes that happen on the way.

You can use the pages in three ways:

- **With the video.** Every lesson page starts with the video at the right moment. Watch a chapter, then read the page to fix it in your mind and to copy the code.
- **Without the video.** Each page is complete by itself. The code is written out in full, so that you do not have to pause and type from the screen.
- **As a reference later.** Every page ends with a table of mistakes and their fixes, and with exercises.

---

## What the course builds up

The course does not start with LangChain4j. It starts with what a model is, then calls a model with nothing except the JDK, and only then brings in the library. By that time you know exactly what the library does for you.

| Part | What you learn | Pages |
| --- | --- | --- |
| 1. AI and LLM fundamentals | What AI, LLMs, tokens, embeddings and transformers are, and why models hallucinate | 7 |
| 2. Calling LLMs from Java | An API key, a raw HTTP call from core Java, the official OpenAI Java SDK | 3 |
| 3. LangChain4j in practice | ChatModel, AI Services, prompt templates, structured output, streaming, REST APIs, memory, tools | 9 |
| 4. MCP and local models | The Model Context Protocol, an existing MCP server, your own MCP server, response metadata, Ollama | 5 |
| 5. Agentic AI | Agents, multi-agent systems, workflows, supervisors, and the final project | 6 |

## What you need

| Requirement | Details |
| --- | --- |
| Java knowledge | Core Java: classes, interfaces, records, lambdas, and Maven projects. Spring Boot basics for the REST API lesson only |
| JDK | 21 is used in the video. LangChain4j needs 17 or newer |
| IDE | IntelliJ IDEA is used in the video. Any Java IDE works |
| An OpenAI API key | With a small amount of credit. The setup lesson shows every step. The cost of the whole course is small, because the examples are short |
| Node.js | Only for the filesystem MCP lesson |
| Ollama | Only for the local model lesson. It can also replace OpenAI in most examples if you do not want to pay for an API |

No knowledge of AI or machine learning is expected. Part 1 starts from zero.

## The projects of the course

The video works in several small Maven projects. Most of them are plain Java with a `main` method, so that nothing hides the code that talks to the model.

| Project in the video | Used for |
| --- | --- |
| `first-app-llm` | The raw HTTP call from core Java |
| `first-lc4j` | The first LangChain4j call, configuration and AI Services |
| `lc4j-demo` | Prompt templates, structured output and streaming |
| `lc4j-springboot` | The REST API with Spring Boot |
| `lc4j-chat-memory-java21` | Chat memory, and then tool calling |
| `mcp-filesystem-starter` | The MCP client, for both MCP servers |
| `course-mcp-server-starter-java21` | Our own MCP server |
| `lc4j-response-metadata-starter-java21` | Response metadata |
| `lc4j-ollama-starter` | The local model |
| `first-ai-agent`, `multi-agent-demo` | Agents, workflows and the supervisor |
| `ai-course-support-assistant-starter-java21` | The final project |

From the chat memory lesson on, the instructor opens prepared starter projects and fills in the important parts. The pages show every file in full, so you can create the same projects yourself. All you need each time is a Maven project with the dependencies listed on the page.

## About the versions

The first LangChain4j projects of the video use version **1.20.0**. The prepared starter projects of the later lessons use **1.18.1**, and for the Spring Boot, MCP and agentic modules the matching versions with a `-beta` suffix, such as `1.18.1-beta28`. Each page names the version it uses.

LangChain4j moves quickly, and the agentic module is marked as experimental by its authors. If something in a newer version looks different from a page, the official documentation linked at the bottom of every page is the place to check.

## How these docs were checked

A mistake in a lesson costs a learner time, so the code on these pages was not only copied from the screen.

- **Compiled.** The Java code of every lesson was compiled against the LangChain4j versions used in the video.
- **Run.** No OpenAI key was used for these docs. The examples were run with local models through Ollama, with the model class swapped and everything else unchanged. Each page says in a box named "Checked for these docs" what was run and what was observed.
- **Compared.** Outputs that are shown as coming from OpenAI are the ones visible in the video. Statements about how LangChain4j behaves were checked against the official documentation.

Where the video does not show a piece of code, the page says so and marks what was completed. Where a run for these docs behaved differently from the video, the page reports both.
